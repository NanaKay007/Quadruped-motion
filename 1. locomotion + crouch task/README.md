# Teaching Spot to walk: A quadruped locomotion task

## Motivation
I took my first robotics class in the Spring of 2025 taught at Stanford titled "CS224R: Deep Reinforcement Learning". However, at the end of the course, I felt the need for more exploratory projects to develop better muscle for reinforcement learning techniques and robotics.

For context, I build web applications as a Software Engineer. While I had some familiarity with ML/Data Science frameworks like numpy and numpy, designing policies for sophisticated robotic tasks required some familiarity with Differential geometry, specifically Configuration spaces and Rigid body motions. I found Northwestern University's Modern Robotics Specialization on coursera to be instrumental.

Then it was time to build! Instead of building from scratch, I picked a reinforcement learning task (Quadruped locomotion) and search for a relevant open-source project, leading me to Federrico's guide [1].
